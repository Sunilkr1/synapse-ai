## 🚀 About Synapse AI
Synapse AI Hub is a premium, feature-rich mobile application designed to bring the world's most powerful AI models into one unified experience. Built with **React Native** and **Expo**, it offers a seamless interface for chatting, comparing, and managing AI interactions.

## ✨ Key Features

- 🤖 **Multi-Model Support:** Chat with Gemini Pro, Groq (Llama 3), DeepSeek, and more.
- 📊 **Comparison Mode:** Ask one prompt and see side-by-side responses from two different models to compare quality and speed.
- 🖼️ **Multimodality:** Full support for image uploads and voice interactions (depending on model capabilities).
- 🔔 **Push Notifications:** Real-time updates and broadcast messages via Expo Notifications & Supabase.
- 🐛 **Structured Bug Reporting:** A dedicated bug reporting system with automatic device info logging and Discord alerts.
- ☁️ **Cloud Sync:** Securely backup your chats and settings to Supabase.
- 🎨 **Dynamic Themes:** Customizable accent colors and support for both Light and Dark modes.

## 🛠️ Tech Stack

- **Framework:** React Native (Expo SDK 50+)
- **Navigation:** Expo Router
- **Backend:** Supabase (Auth, Database, Edge Functions)
- **State Management:** Zustand
- **Icons:** Lucide React Native
- **Styling:** Vanilla CSS with custom theme system

## 📦 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Sunilkr1/synapse-ai.git
   cd synapse-ai
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Setup Environment Variables:**
   Create a `.env` file and add your Supabase credentials:
   ```env
   EXPO_PUBLIC_SUPABASE_URL=your_url
   EXPO_PUBLIC_SUPABASE_ANON_KEY=your_key
   ```

4. **Run the app:**
   ```bash
   npx expo start
   ```

## 🔒 Security & Privacy
Synapse AI is built with privacy in mind. Your personal API keys are stored securely on your device or in your private Supabase vault. We do not track your personal chat data for training or advertising.
